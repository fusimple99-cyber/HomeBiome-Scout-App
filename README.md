# HomeBiome Scout: AI-Driven Oral Microbiome Monitoring System

## 🌟 Project Vision
[cite_start]HomeBiome Scout is an innovative interactive system designed to bridge the gap between microscopic biological data and daily health management[cite: 3, 5]. [cite_start]By monitoring oral microbiota changes over a 30-day cycle, the system provides early warnings for potential disease risks[cite: 3, 30].

## 🛠 Interactive Eco-system
[cite_start]This repository contains the cross-platform application (Web/Mobile/Pad) that serves as the "translator" for the HomeBiome Scout hardware[cite: 11, 12, 45].

- [cite_start]**Interactive Teaching**: Step-by-step guidance for users on saliva collection and test strip replacement[cite: 60, 68].
- [cite_start]**30-Day Data Visualization**: Transforms complex bacterial parameters into intuitive health trends[cite: 13, 52].
- [cite_start]**Hospital Connection**: Automatically notifies users and coordinates with medical institutions when disease risks are detected[cite: 6, 34].

## 📱 Tech Stack & AI Integration
- **Framework**: Developed using AI-assisted prototyping tools (Google AI Studio) to ensure full responsiveness across devices.
- [cite_start]**AI Logic**: Integrated LLM capabilities to analyze "Microbiota Detectors" data and generate personalized health advice[cite: 13].
- [cite_start]**Hardware Integration**: Designed to sync with the "Round Detection Box" via data storage ends[cite: 27, 70].

## 🚀 How it Works (Interaction Loop)
1. [cite_start]**Daily Test**: User extracts saliva using the "Saliva Extractor"[cite: 32].
2. [cite_start]**Data Sync**: The test strip is placed in the medical box, syncing data to this app[cite: 45, 71].
3. [cite_start]**AI Analysis**: The app processes the 30-day dataset to identify health anomalies[cite: 12, 51].
4. [cite_start]**Action**: Provides "Health Cycle Closure" by notifying hospitals or recommending check-ups[cite: 6, 42].
